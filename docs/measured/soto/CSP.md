## ★② CSP を 入れたら 何が 止まるか（実測）★

★手元に 同じ 画面を 立てて、そこにだけ CSP を 付けた★
★止まった 物は ★ブラウザ自身に 言わせた★（securitypolicyviolation）★

### ★(あ) 中に 書いた 物を 許さない 形 … ★864件 止まる★★

```
  default-src 'self'
  script-src  'self' https://cdn.jsdelivr.net
  style-src   'self' https://fonts.googleapis.com
  font-src    'self' https://fonts.gstatic.com
  img-src     'self' data: blob:
  connect-src 'self' https://*.supabase.co
```

| 止まった 物 | 数 |
|---|---|
| `style-src-attr`（`style="…"` を 直に 書いている 所） | ★855回★ |
| `style-src-elem`（`<style>` の 中） | 4回 |
| `script-src-elem`（`<script>` の 中） | 3回 |
| わざと 止めた 2つ（物差しの 確かめ） | 2回 |

```
 ⇒★★この 形は 使えません★★
 ⇒ 理由＝`book.html` は ★`style="…"` を 855か所 直に 書いている★
 ⇒★直すと したら 855か所＝別の 大仕事★
```

### ★(い) 中に 書いた 物を 許す 形 … ★止まるのは 2件だけ★★

```
  script-src  'self' 'unsafe-inline' 'unsafe-eval' https://cdn.jsdelivr.net
  style-src   'self' 'unsafe-inline' https://fonts.googleapis.com
  （他は 同じ）
```

```
 ★止まった 2件は ★どちらも 私が わざと 撃った 物★★
   ・許していない 相手の 絵     … img-src が 止めた
   ・許していない 相手への 取得 … connect-src が 止めた
 ⇒★★画面の 物は 1つも 止まっていません★★
```
